# Example bezier dataframe to grow leaves on

Generated with
[`vignette("import_svg_bezier")`](https://urswilke.codeberg.page/ggbenjamini/articles/import_svg_bezier.md)

## Usage

``` r
df_bezier_skeleton
```

## Format

A data frame with 40 rows and 4 variables:

- i_branch:

  branch index

- svg_point_type:

  original point type in the svg file

- x:

  x coordinate

- y:

  y coordinate
