# Generate bezier end points

Generate bezier end points

## Usage

``` r
gen_benjamini_points(leaf_params = gen_leaf_parameters())
```

## Arguments

- leaf_params:

  parameters generated by
  [`gen_leaf_parameters()`](https://urswilke.codeberg.page/ggbenjamini/reference/gen_leaf_parameters.md)

## Value

tibble with absolute coordinates

## Examples

``` r
gen_benjamini_points()
#> # A tibble: 5 × 2
#>       x     y
#>   <dbl> <dbl>
#> 1    10  40  
#> 2    22  40  
#> 3    39  32  
#> 4    51  38.6
#> 5    56  40  
```
