# Generate bezier slopes coordinates

Generate bezier slopes coordinates

## Usage

``` r
gen_benjamini_slopes(leaf_params = gen_leaf_parameters())
```

## Arguments

- leaf_params:

  parameters generated by
  [`gen_leaf_parameters()`](https://urswilke.codeberg.page/ggbenjamini/reference/gen_leaf_parameters.md)

## Value

dataframe with sx1-4 in the x variable and sy1-4 in the y variable

## Examples

``` r
gen_benjamini_slopes()
#> # A tibble: 5 × 2
#>        x      y
#>    <dbl>  <dbl>
#> 1 0.0334  0.693
#> 2 1      -5    
#> 3 4      -0.493
#> 4 4       0.864
#> 5 0.0944  0.463
```
